# FitQuest－遊戲化健身養成系統

FitQuest 是使用 Java Swing 製作的桌面健身紀錄與角色養成系統。使用者可以記錄有氧與阻力訓練，系統會依運動內容計算 XP、更新角色等級與肌群成長，並以「正面／背面 2D 像素人偶動態四階級縮放引擎」、自適應多尺度堆疊趨勢圖表、日曆及歷史紀錄呈現訓練成果。

核心特色：

* 紀錄有氧與阻力訓練，內建 70 種科學運動項目。
* 結合性別、年齡與「Jannsen 骨骼肌質量幾何解析公式」估算全身純肌肉量（SMM）作為強度分母，杜絕肥胖新手與精壯巨巨的數據失衡。
* 阻力強度採用「希爾飽和型非線性函數」與自重訓練 65% 軀幹負重代償演算，完美導引玩家挑戰「70%~80% 1RM 黃金肌肥大區間」。
* 升級門檻採用「動態多段式線性與阻尼級數」，徹底斬殺高難度下的指数通膨，提供長青且正向的 RPG 升級反饋。
* 2D 像素雙面人偶堆疊引擎，具備「關節自體膨脹」與「胸肌變寬被動外推手臂」的跨部位連動微調演算。
* 支援「歷史紀錄滑鼠右鍵刪除選單」，內建「大腦逆向退化引擎」，撤銷時空數據時可精準扣除對應的 XP 與肌肉量，具備極佳的資料容錯彈性。
* 提供日曆、運動提醒、個人資料、成就牆與全進度資料清空功能。

## 目前主要功能

* **新增／紀錄運動**：可搜尋及分類選擇運動，輸入重量、次數／分鐘、組數，勾選後一次送出多筆紀錄。
* **自訂訓練菜單**：訓練菜單會保存於 `data/custom_menu.properties`。
* **角色資訊與稱號持久化**：首頁顯示玩家名稱、戴配稱號、角色等級及 XP 進度條。稱號變更後會永久寫入 Properties 存檔。
* **正面／背面四階像素人偶**：依玩家總等級及各肌群等級組合不同部位圖片，具備不分大小寫模糊匹配，徹底相容組員美術命名。
* **部位成長與部位等級卡**：阻力訓練會依運動對應肌群增加部位原始值；首頁下方設有 5 大肌群 Lv 卡片，以對應顏色邊框高亮渲染。
* **今日任務與溢出防護**：顯示今日訓練量、完成組數、訓練部位與三項任務完成狀態。訓練部位字數過多時會自動觸發智慧切片保護（最多顯示三個動作並以 `...` 代替，懸浮提示可看完整清單），徹底防範界面破圖。
* **自適應堆疊趨勢圖**： Y 軸採用物理工作量綱（Total Volume = 重量 × 下數 × 組數）。
* 週規模：本週星期日至星期六，每根柱代表一天。目標與過載警報防線會自動換算為物理公斤噸數（目標線 4500kg，極限過載線 12150kg）。
* 月規模：將當月分為五個日期區間。防線自動乘以 6 倍。
* 年規模：每根柱代表一個月。防線自動乘以 30 倍。


* **歷史紀錄與容錯**：首頁顯示最近 5 筆運動紀錄，完整資料保存在 CSV。支援選取任一列**點擊滑鼠右鍵**進行資料刪除與逆向大腦數值扣除。
* **日曆與提醒**：可查看每日運動、建立提醒，程式啟動後會檢查提醒時間。
* **成就與稱號**：具備成就牆，利用 `APPLICATION_MODAL` 阻塞機制，解決多成就、多等級連發被吞掉的 Bug，確保依序彈出通知。
* **個人資料與科學數值**：可設定身高、體重、年齡、體脂率（選填）、目標體重與增肌／減脂目標，顯示 BMI、BMR、TDEE 滾動加權值，以及純骨骼肌質量（SMM）。
* **清空資料**：首頁提供確認視窗，確認後才會重置玩家進度、運動紀錄、成就及行事曆計畫。

## 專案執行方式

### 環境需求

* 建議使用 **JDK 21**。目前原始碼已使用 JDK 21 編譯驗證。
* 不需要 Maven、Gradle 或第三方套件；UI 使用 Java Swing，圖片讀取使用 Java 內建 `ImageIO`。
* 請從專案根目錄執行，因為 `assets` 與 `data` 都使用相對路徑。

確認 Java 版本：

```powershell
java -version
javac -version

```

### 編譯與執行

在專案根目錄使用 PowerShell：

```powershell
# 官方遞迴編譯管線命令
javac -encoding UTF-8 -d demo-out FitQuestApp.java (Get-ChildItem src -Recurse -Filter *.java).FullName
java -cp demo-out FitQuestApp

```

根目錄的 `FitQuestApp.java` 是唯一正式入口，只負責將程式交給 `fithero.app.FitQuestApplication` 啟動。

`demo-out` 是可重新產生的編譯輸出資料夾，已加入 `.gitignore`，不應提交至 GitHub。所有正式 Java 原始碼都在根目錄入口或 `src` 內。

首次執行時，程式會要求建立使用者資料，並自動建立 `data` 資料夾。`assets` 資料夾必須保留在專案根目錄，否則角色會退回顯示簡易線條人偶。

## 重要程式邏輯

### XP 如何計算

主要公式位於 `src/fithero/logic/calculator/ExpCalculator.java`。

有氧運動：

```text
消耗熱量 = (分鐘 / 60) × MET × 玩家體重
XP = 消耗熱量 × 0.5

```

阻力訓練：

```text
非自重熱量 = (重量 × 次數 × 組數 × 0.06) × (玩家體重 / 70)
自重熱量   = (玩家體重 × 0.1) × 次數 × 組數 × 0.05
XP         = 熱量 × 0.3 + 訓練強度 × 4.0  

```

自重訓練（自體負重動作且未輸入重量時），力學分子會自動轉換為玩家體重之 `65%` 軀幹負重比重，給予徒手健身流派應有的科學強度。

### 等級如何提升（多段式安全引擎）

為了防止玩家後期升級阻力無限爆炸，升級公式已重構為**三階段動態多段式線性與阻尼級數**，由 `PlayerState.checkLevelUp()` 執行：

* **A 階段 (1~15級)**：下一級需求為 `100.0 + (nextLevel - 1) * 50.0`
* **B 階段 (16~40級)**：下一級需求為 `800.0 + (nextLevel - 15) * 110.0 + (nextLevel * 5.0)`
* **C 階段 (41級以上)**：下一級需求為 `3600.0 + (nextLevel - 40) * 400.0`

### 各部位等級與四階級動態縮放對應

* 顯示用部位等級由 `PlayerState.muscleLevel()` 進行開根號阻尼計算：

$$\text{部位顯示等級} = \lfloor\sqrt{\text{部位原始值} \times 0.7}\rfloor + 1$$


* 獲得的部位顯示等級會傳入 `AvatarPanel` 的生理模型中，進行**實體圖片切換**與**階級內微幅線條膨脹（scaleBonus）**：

| 顯示等級區間 | 實體素材（fileLevel） | 階級內微幅放大紅利（scaleBonus） |
| --- | --- | --- |
| 1 ~ 10 級 | `lv1` | 每升 1 級，線條物理體積等比例膨脹 `1.5%` |
| 11 ~ 25 級 | `lv2` | 每升 1 級，線條物理體積等比例膨脹 `1.5%` |
| 26 ~ 50 級 | `lv3` | 每升 1 級，線條物理體積等比例膨脹 `1.2%` |
| 51 級以上 | `lv4` (封頂) | 鎖定滿階圖片，最大等比例安全放大 `1.25` 倍 |

四肢（手臂與腿部）會隨著 `fileLevel` 計算對應的關節外移步長 `_OUT_STEP`。同時，當正面胸肌（CHEST）升級變寬時，手臂會自動受到跨部位連動演算干擾，被動向外推移，防止圖層重疊與變形。

### 訓練量與圖表防線量綱對齊

首頁任務與趨勢圖共用 `WorkoutEntry.trainingVolume()` 計算物理公斤工作量。
圖表實作於 `src/fithero/ui/WorkoutBarChartPanel.java`，為了與總重量（Volume）量綱對齊，圖表內置了自適應轉換係數：

* **週規模防線**：目標線拉高為 `4500 kg`（dailyTarget * 4.5），過載危險線拉高為 `12150 kg`。
* **月、年規模防線**：分別自動乘以 6 倍與 30 倍。
當長條圖超越該防線時，柱頭會自動噴出高亮「達標」與「過載」文字，且標籤加入 `Math.max(26, ...)` 邊界調節鎖，永不衝出畫布頂端。

### 右鍵資料容錯與大腦退化

首頁表格綁定滑鼠右鍵點擊事件。當使用者點擊「刪除此筆紀錄」時，觸發 `PlayerState.deleteWorkoutReward()`：

* **經驗值倒流**：扣除該動作產生的所有 XP，若扣除後小於 0，大腦會反向運算，將玩家降級並退回前一等級的經驗值池。
* **肌肉流失模擬**：大腦會逆向反推該動作當初產生的 `muscleGain`，並將該部位肌肉原始值進行精準扣除，隨後調用 `saveAndRefresh()` 即時重繪，讓角色體態當場「退水腫」縮回正確尺寸。
