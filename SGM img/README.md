# 正反面 2D 人偶狀態顯示系統

## 目前功能

- 正面與背面人偶同時顯示
- 身體、胸部、腹肌、手臂、腿部、背肌可獨立切換等級
- 每個部位都有等級下拉選單與升級按鈕
- 支援「全部重設」與「全部最高」
- 背面手臂、腿部或身體素材缺少時，會 fallback 到對應正面素材

## 正反面繪製內容

正面：

- 身體
- 腿部
- 手臂
- 胸部
- 腹肌
- 頭部與臉部表情

背面：

- 背面身體
- 背面腿部
- 背面手臂
- 背肌
- 背面頭部

背面不會繪製胸部或腹肌。背肌擁有獨立等級，只影響背面背肌圖片。
